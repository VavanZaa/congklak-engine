# Saved-data investigation of the ordinary value pilot

This is an exploratory investigation designed after seeing the prior pilot, not a new blind evaluation. It explains the existing admitted-pool overlap hold, H_v1 game losses and requested-H10 validation errors before any further training. The original allocation remains HOLD. H_v1 remains the default; the compact control remains the learned candidate. No policy, trunk, value weight, optimizer, dataset, old report or allocation is changed.

The baseline is `build/ordinary-value-review-baseline.json`: all 3,776 prior acceptance inputs plus the acceptance, immutable-rerun and final-dashboard artifacts, for 3,779 protected files. Review files use new `ordinary-value-*-review` or `ordinary-value-review-*` names. Read old SQLite databases through mode=ro only. Do not invoke prior producers or suites that publish old artifacts.

## Work and cost bounds

New training updates, teacher searches, PUCT searches, strength games, self-play rollouts and Torch imports are all zero. Literal legal replay and deterministic CPU exported-model/feature calculations are allowed. No wall-clock strength or energy claim is produced by this review.

1. Overlap: scan all 7,587 admitted optimizer rows, the independently reconstructed 12,800-draw ledger and all 3,268 saved arena decisions. Rebuild the original active>4 quotient/family test. Separately count exact raw-state, player-swapped full-state, player-swap/store-offset quotient and origin-family matches, each for admitted and actually drawn pools. Retain every collision, orientation, aligned stores and actor, integer store offset, current draw count and target semantics. Quantify active-band patterns and pre-existing role masks. Do not transfer labels across a quotient or treat zero current draws as proof of no ancestral exposure. The historical report's `contaminated_evaluation` flag means its frozen admitted-pool guard, not proof of current-gradient leakage. Any alternative gate result is explicitly hypothetical; no branch or data collection is changed.

2. Arena: retain all 96 games and 3,268 legal choices, all 12 families and both seats for both baselines. Compare the fixed-value candidate with the contemporaneous control, including all absolute H_v1 losses, unchanged trajectories and matched margins. Record every first shared-prefix divergence, actor/engine ownership, raw state, mechanism/band, saved policy priors, root value/Q/visits/simulations/depth, timing and physical costs where actually stored. Compare the first divergent actions only to already-saved references for exactly the same full state; missing Q remains missing. H8 relay is context, not a new experiment. Saved unequal visit counts and timed opponent choices prevent unique attribution of a game result to value weights. Captures and local stores are observations, not proof of a blunder. No selected loss alone represents the whole cohort.

3. Validation: retain all six reserved roots, all three requested horizons and both fixed models. Derive player0 and actor-oriented values, store offsets/active scale, normalized residual targets, signed/absolute errors, high/low summaries and per-root contribution to the H10 aggregate change. H8/H12 sensitivity uses the same predictions; H10 remains the original primary reference, and no horizon is exact full-game truth. Decompose final-head preactivation changes into bias and hidden-weight contributions, verify frozen policy/trunk, and report tanh interval representability. For descriptive step-direction sensitivity only, fixed preactivation interpolation coefficients are {0, .25, .5, .75, 1}; they do not select a model or checkpoint and are never exported.

4. Sampling and coverage: reconstruct the declared 3,200 high /3,200 low /6,400 rehearsal draws and the two observed outcomes for each of 24 ordinary starts. Report actual effective exposure and outcome spread, with different terminal-policy and approximate-H8 estimands kept distinct. For each validation root, select exactly five nearest admitted rehearsal roots by declared actor-relative pit L1 distance, tie by row ID; this is feature-only selection, not target selection or a claim that nearby boards have nearby game values. Compute literal forwards for at most the union of 30 selected rehearsal roots, 24 ordinary start states and six validation states. Existing cached features may support all-row numerical summaries. No labels from validation enter training, weighting, pruning or a new draw pool.

## Independent checks and publication

The learning and arena implementers own separate new modules/tests. A third agent independently rederives overlap/draw/transform facts, all matched games and divergences, six-root model errors/horizon sensitivity and policy identity. It checks cross-report denominators and inference limits, rejects rehashed corrupt review metrics/source identities, rebuilds missing outputs into new fixture locations and verifies stable completed API/CLI reruns with search/training/Torch prohibited. New reports are deterministic immutable atomic publications; an interrupted review can rebuild from immutable saved evidence. Previous game/optimizer kills are not counted as new tests or rerun.

The root integrates the results and updates a new observer on the existing local dashboard port without changing accepted observer source. Dashboard backend checks must leave old artifacts unchanged; earlier denied browser access is not retried. Final acceptance pins current review sources, reports and source-bound executed checks, preserves all 3,779 old hashes, verifies completed publication and dashboard status, and starts no collection or training.

Recommendations must distinguish established arithmetic from hypotheses. In particular, an admitted-but-undrawn late quotient match is not automatically a raw-state or gradient match; small training-fit gains are not strength; six dependent finite-reference roots and consumed arena families are not a release test. Any revised protection policy, deeper targeted labeling or controlled value/search experiment is a prospective next scope, not a retroactive repair of this pilot.
