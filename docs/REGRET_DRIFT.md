# Regret diagnostic producer contract

`congklak/regret_drift.py` reads the sealed qstability study directly and performs exact arithmetic without an engine or model runtime. `docs/REGRET_SCOPE.md` is the scientific and persistence scope. Both the original max-action weighting rule and every U/W probability remain unchanged.

`source()` validates the actual hashes of the qstability journal, complete manifest, immutable H8/H10 prefix, prefix manifest, registry, rule, result, reservations, plan and implementation against the 5,252-input regret baseline. It checks source row digests, typed production identity, all16 raw states, all48 complete requested endpoints, consecutive histories, TT16/PVS, source-root versus wrapper hashes, exact H8/H10 frozen endpoints and the pure metrics reconstruction of the sealed result. Relevant accepted arithmetic/literal helper sources and both model files are checked on every call; the independent audit and final closure verify every prior file. No mtime cache or old producer admission API is used.

The fixed detailed case order is family178 bonus, then capture91,382,92,390. `context(data)` serializes every legal action for all16 roots, all three horizon pairs, full-tie regrets, signed/rank/cancellation diagnostics and exact per-root contribution maps. Each `context.roots[key].pairs[pair].metrics[metric]` has `value`, `uniform_global_contribution`, `weighted_global_contribution`, and `global_weighted_minus_uniform`. `context.cells[cell].pairs[pair].metrics[metric]` records the exact two-root covariance identity. `context.scopes[pair]` retains overall/capture/noncapture/ordinary/stratum/cell/actor/detailed/remainder masses, global totals, conditional risks, and U/W differences. These distinct denominators are explicit; the five detailed cases do not replace the 16-root panel.

`action_analysis(row,endpoints,probability)`, `translation(deltas)` and `covariance_identity(raw,metrics,cell_mass=1/8)` are pure exact helpers, including full ties, actor1 minimization and singleton synthetic support. `regret_forensics.build_case(row,items_by_stage,attempts_by_stage)` adds literal PV evidence for the five detailed cases. The accepted capture-forensics replay/ranking functions may be reused read-only; their source hash is pinned explicitly. A new wrapper validates the actual bonus/capture roles and exact source linkage without pretending the bonus case is capture.

## Public interface and files

- `prepare()`, `plan()`, `freeze()`, `admit()` publish or validate new `build/regret-drift-{panel,plan,implementation,source-freeze}.json`. Source freeze includes both owner test definitions and the final helper dependency freeze before any formal fixture. `settings_for(fixture=False,cases=None)` strictly requires a boolean; production is exactly five cases at the default path, fixture1/2 cases are restricted to `build/`.
- `run(path=DEFAULT, fixture=False, cases=None, on_event=None, cancel=None)` returns a complete manifest after case commits. `load_rows(path=DEFAULT)` returns `(cases, manifest)` only after exact closed validation and manifest agreement. `DEFAULT` is `data/regret-drift-v1`; `work.sqlite3` has `meta(key,body,hash)` and `cases(idx,body,hash)` with indices0..4. All bodies have canonical SHA-256 digests.
- `compute_case(index,data)` produces the indexed case's exact source links, unchanged probabilities, numerical analysis and literal forensics. The payload exposes `case_id`, `state_key`, `state`, `actor`, `cell`, `family`, separate `source_root_sha256` and `source_wrapper_sha256`, per-stage endpoint/attempt hashes, `analysis` and `forensics`.
- `build(path=DEFAULT)` rederives the whole deterministic report; `assess()` immutably publishes `build/regret-drift-result.json`; `validate_report(report,path=DEFAULT)` and `verify(path=DEFAULT)` reject any metric or identity mismatch by full canonical recomputation. Result fields include `status='complete'`, `cases=5`, `context`, `case_results`, and `summary` exact global/capture/noncapture Q-drift and mean-best-regret deltas. All no-training/no-new-search/no-NN/no-game/no-promotion flags remain explicit.
- CLI `python tools/investigate-regret.py prepare|plan|freeze|run|all|verify-cases|assess|verify`, optionally `--fixture --cases 2 --run <build-path>`. `all` publishes the final result only for production. Use `python -m congklak.regret_progress run --tool NAME -- python ...` for durable progress logs. Owner proof is `build/regret-drift-author.json` with four exact method IDs and current source pins.

The real-kill events are `regret_precommit` and `regret_committed`, with `completed` durable prefixes1/2 around the second case, `target`, `state_key` and `case_index`. `REGRET_BLOCK_EVENT`, `REGRET_BLOCK_STEP` and `REGRET_MARKER` flush an event/marker and wait for the independent hard kill. `regret_drift_complete` reports completion. A token or callable can cancel at boundaries; only the uncommitted case arithmetic may repeat.

The complete marker is validated before any export repair, including on `run()` reopening. Intact completed reopening performs no commits or writes and preserves durable hashes/sizes/mtimes, including writer lock and nonempty WAL; ephemeral SHM and absent/empty WAL are excluded. Arithmetic and literal semantic validation may repeat. The independent guarded workers forbid every Native entry point as well as neural/search/training/Torch paths, rather than interpreting 'no new work' as zero validation CPU.

The four meaningful owner checks cover sealed support/all16 contribution/covariance reconstruction; signed full-tie/cancellation/crossover synthetics; public CLI/cancellation/source gates and retained-prefix resume; and rehashed corruption, publication repair, report refusal and completed no-work. Independent six-method coverage adds two physical kills, all-source numerical/literal checks and final corruption/no-work closure. No favorable diagnostic changes the fixed rule, creates a training example or authorizes another experiment.
