R1 and R6 can use a small local state machine, not a distributed lease system: committed root, retained fallback, retired generation, and pending physical deletion. A file shared by several generations is reclaimable only after the final live edge releases it. Failed deletes stay in quota accounting and are retried. A checksum validates bytes; the legal-state/result verifier validates their meaning.

## Concrete first implementation gates

1. Freeze one rule profile, canonical state encoding and margin objective, then complete the independent reference/production transition checks. The first CLI should reject unsupported profiles, history and transient sow states.
2. Implement one deterministic CPU worker with full-width alpha-beta and a fixed evaluator, explicit depth semantics and bounded cancellation checks. Publish all legal candidates with their actual completion/bound status. Optional TT/PVS optimizations follow conformance checks.
3. Choose an explicit local data directory, initialize/validate the SQLite schema and save input, immutable rule contract, settings, prior report and new coherent report atomically. A partial iteration never replaces the last complete ranking. Preserve report provenance on reopening; reuse it as an estimate only under compatible semantics.
4. Implement the selected 512 MiB managed-memory starting budget and process monitoring beneath the shared 24 GiB ceiling, plus physical 50 GiB storage admission. The first inline analyzer reserves at least 256 MiB recovery headroom; later bulk operations reserve the complete replacement plus at least 2 GiB overhead. These settings need measured enforcement tests. The 12 GiB GPU starting cap is a later-job limit; the first analyzer needs no GPU allocation or trained model.
5. Terminate the analyzer before/after completed-result commits and repeat restart. Test cancellation in long relay transitions, full disk, failed metadata writes, incompatible rule/evaluator versions and corrupt reports. Verify that recovery retains a valid coherent explanation or returns a recoverable error, then completes a fixed-horizon analysis with the same values/tie convention as uninterrupted search.
6. Before enabling each later job, add its own checkpoint and data gates: unique/idempotent game IDs; consumed-batch trainer checkpoints; verified coverage/proof closure for exact jobs; and the transactional artifact retirement/reserve protocol before any bulk compaction or pruning.

These are documentation/implementation gates, not completed acceptance results. None implies that arbitrary recursive instructions, GPU scheduling or sudden power loss have been restored exactly.
