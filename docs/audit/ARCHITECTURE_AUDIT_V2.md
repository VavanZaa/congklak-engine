## Contracts that already pass this review

- Candidate A's omissions are identified as engineering proposals. Immediate sweep, circuit-restricted capture, simultaneous openings, refill, closed and protected pits remain distinct contracts. The board diagram, `6-index` opposite mapping, opponent-store skipping, source revisits, occupied-final-pit relay and completion-before-settlement fixtures agree internally.
- Stable choice boundaries exclude hand/cursor animation state. Deterministic sowing is one transition; bonus choices are separate branches. Forced passes use no decision depth and remain visible in trace/control metadata. Guard exhaustion returns unknown/error rather than an invented draw.
- Fixed-player MAX/MIN recursion correctly handles consecutive bonus choices and normalized passes. A later current-player negamax or PUCT backup reverses value/window only when the actual actor changes. Published player-1 scores and intervals require `score -> -score` and `[L,U] -> [-U,-L]` from the internal player-0 convention.
- TT `EXACT` is scoped to compatible finite horizon, evaluator and extension policy. A greater-depth heuristic entry is not an exact shallower-tree answer. Full canonical equality or collision-free ranking is required for proof-relevant retrieval. Deliberate collisions and torn-entry handling are correctly called out.
- PVS cutoff alternatives retain bounds or undergo full-window re-search. Completed MultiPV publication requires comparable per-candidate coverage; a cancelled iteration preserves the prior coherent ranking. Integer null windows require an integer score convention in the selected first evaluator.
- Both-empty terminality and pass/revival are correctly distinguished. Permanent-store factorization and symmetry remain proof obligations. Active-seed layers can contain same-layer dependencies; termination needs an internal rank or a complete graph procedure rather than active-seed count alone.
- Two-byte future-value/mask storage is feasible for K<=12 under the fixed single-round quotient, but is payload sizing only. Additional rule state, exact indexing, graph construction, coverage, checksums and proof metadata require separate memory budgets.
- The proof verifier regenerates actions, transitions, terminal payoffs and required dependencies with the independent interpreter. MAX lower-bound certificates may witness one child while MAX upper bounds cover all; MIN reverses the obligations. Cycles need their declared adjudication and a valid graph certificate. Strong play, WDL proof, exact margin, starting-state strategy, and a declared all-state domain remain different claims.
- Learning, GPU PUCT and broad solving remain later experiments. Exact oracle holdouts are separated from lookup-assisted product benchmarks. Teacher estimates, exact labels, certified intervals and game returns have distinct meaning. Protected exact coverage cannot survive deletion of its backing entries.

## Concrete first implementation slice

1. Freeze a complete single-round candidate-A engineering contract and coordinate map, clearly labelled experimental rather than user-confirmed. Support only its ordinary stable choice/terminal input forms; reject simultaneous, refill, closure, protected-pit and mid-sowing inputs until implemented deliberately.
2. Implement an independent seed-by-seed reference interpreter and a straightforward C++ copy/apply kernel with explicit deposits. Produce canonical input bytes, legal choices, normalization/pass events, complete action traces and exact terminal margins. No lap compression, undo journals, symmetry quotient or neural model is needed.
3. Add a versioned local JSON CLI: validate, list/apply/trace, analyze, cancel and reopen. Use fixed-player integer store difference at depth-zero leaves, terminal outcomes at terminal states, no exact-oracle substitution initially, and full-width deterministic alpha-beta over every legal root move with simple iterative deepening. Count every pit choice, including bonus choices, toward remaining depth. Root moves at a reported horizon must share completed semantics.
4. Commit the canonical input/settings and each completed-iteration report inline in SQLite transactions. Retain the last complete report. Reopening restores the input, rule/evaluator/horizon identities and coherent report, then recomputes unfinished work. Bulk immutable-file publication is a later dependency, not a prerequisite for this release.
5. Add TT, aspiration/PVS optimizations and K=4 exact knowledge only in separate conformance-preserving steps. K=6/8, training, PUCT, MTD(f), the D1 reproduction and root proof campaigns are follow-up work selected by evidence.

Objective first acceptance gates:

- Rule card, JSON and trace numbering agree. Validate conservation and count ranges; reject unsupported semantic state. Run every existing synthetic fixture and both-player transforms, including empty-opposite, source revisit, pass/revival, captures and bonus endings.
- Publish a deterministic exhaustive small-instance test domain and reference/production comparison. The selected initial scope uses separate small test profiles with one to three pits per side and up to six total seeds, plus generated legal 98-seed histories and curated long-relay/bonus-chain inputs for the supported seven-pit profile. Include both controllers and appropriate store offsets. These are conformance inputs, not claims of opening reachability or a K=4 tablebase release.
- Compare plain exhaustive finite-horizon reference minimax and alpha-beta for all declared small test states/horizons. Include repeated same-actor choices, pass-normalized same actor, player-1 roots, terminal-at-root, equality/tied choices and cutoff-bound alternatives. Any failed/incomplete candidate stays partial; proof fields remain unset except independently sound terminal/physical facts.
- Cancel during relay work, root work and publication; reopen the last valid completed iteration and continue to the same deterministic scores/moves/traces under a fixed node/horizon budget. Inject truncated/missing latest artifacts and interrupted manifest publication; fallback or explicit recoverable failure must preserve completion truth.
- Record latency, peak RAM, trace work and disk writes for this release. Establish any interactive latency/energy target after these measurements. A network, complete K=8 tablebase, matched paper-profile opening proof and broad solver are not acceptance prerequisites.
