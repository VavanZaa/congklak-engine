## Concrete initial label contract

Each state is a stable decision state after the frozen rule profile's forced-control normalization. Retain the imported and normalized controller identities when explaining a pass. Use a fixed player perspective in the durable record; a controller-relative loader may transform it only with an explicit player/action map. Extra choices do not alternate signs. `D` is the selected target player's current store difference, `R` is all seeds outside permanent stores, and a terminal state uses the rule result without dividing by zero.

For an initial scalar margin example:

1. Verify counts, conservation, rule/objective/encoding identity, stable phase and legal actions before expensive labeling.
2. Reject all final-test ownership classes and their excluded family/game relatives, then canonicalize verified transformations with a recoverable inverse map.
3. Prefer a compatible independently verified exact margin. Preserve its proof/coverage ID and all tied optimal actions.
4. Otherwise admit one complete teacher result in the selected teacher contract. Preserve exact finite-horizon versus operational estimate status, evaluator digest, tablebase/oracle-mask manifest, completed choice horizon, opponent-reply coverage and every root-action completion/bound flag. A complete best score need not imply a complete policy target.
5. Bounds receive no point-target loss initially. Interrupted work receives no synthetic outcome. Game returns remain in a separate outcome table/head/experiment and cannot replace optimal-margin targets.
6. Check physical target eligibility and perspective transforms. An incompatible or noisy label goes to relabel review or bounded quarantine; high prediction error alone does not increase its reliability.

When several compatible teacher revisions exist, use a selected-production-teacher revision and predetermined completed budget class, with increased-budget comparisons on a fixed pilot subset. A revision that changes the best move or margin beyond a predeclared seed tolerance is a relabel candidate; it is not automatically reliable because it consumed more nodes. Log the selection reason. Do not average conflicting exact answers, unrelated horizon evaluators, or different generator-policy outcome returns into one optimal label.

## Concrete initial sampling and retention experiment

Use a frozen 10,000-position pipeline pilot before the 100,000-position comparison. Define an intended distribution over disjoint active-seed/source strata, while mechanism tags are used for declared coverage quotas and reports. Record all stratum masses and unique-state counts. Uniform conditional sampling inside each selected stratum is the first baseline. The state-admission reservoir provides rare-mechanism representation; initially its retained unique states have equal conditional probability. No model-error sampling or error-based removal is needed to make this baseline useful.

After that baseline passes, a proposed sampling experiment may use `P(i)=0.3*q(i)+0.7*r(i)`, where `r` is a frozen, capped-priority distribution and `q` is the baseline objective. Start with independent draws with replacement; an epoch or batch sampled without replacement needs its own inclusion-probability estimator rather than blindly reusing this per-draw formula. This exact mixture guarantees support and bounds `q/P` by `1/0.3`; the 30/70 ratio remains an experiment, not an established optimum. Prefer disjoint sampling routes. For overlapping routes, store the marginal probability. Use full correction first; partial or clipped correction changes the experiment and must be named.

For eligible, stable labels, priority can start with `epsilon + min(abs(seed_prediction_error), error_cap)` using a versioned frozen model. Specify `epsilon` and the seed-unit cap before the run. Novelty and rarity can instead change the declared stratum distribution; avoid adding both oversampling and a second rarity loss multiplier. New records start with neutral priority until validated, rather than indefinite maximum priority. High-error unstable teacher labels receive relabel priority and normal capped sampling, with no confidence upgrade. Compare teacher coefficient settings and priority changes separately, so a change has an interpretable cause.

Set explicit protected retention floors by active-seed/source stratum and mechanism, and keep a bounded uniform reservoir of older compatible teacher generations for rehearsal. These floor counts are pilot parameters recorded in the manifest, not universal constants. Under disk pressure first reclaim temporary/debug artifacts, exact duplicate payloads and superseded unreferenced revisions. Retain every game required by selected outcome provenance, frozen evaluation sets, proof/coverage dependencies, the current and previous accepted model, and recovery generations. Immutable compaction and the existing 50 GiB aggregate quota remain appropriate. If protected artifacts exceed it, stop new production and report the resource decision.

## Staged acceptance and honest reporting

The ordered gates should be: frozen rules and reference/production simulator conformance; useful resumable CPU analysis; pilot generation/label/canonicalization/split tests; uniform small dense evaluator; CPU export and inference conformance; measured count-embedding/NNUE challenger; only then weighting, prioritized sampling, relabeling and retention ablations; later PUCT/self-play. An independently verified K=4 tablebase is a small follow-on oracle and validation aid. Its K=6/8 expansion requires measured benefit and construction costs, and does not block the pilot or first training comparison.

Promotion uses development exact margin error and move regret, tactical/pass/bonus-chain coverage, equal-time analysis and arena evidence. Report raw evaluator performance with oracles masked separately from complete-product lookup performance. Freeze the winning candidate/settings, then evaluate the sealed final test with a predefined budget and strata. Report tie-aware errors, uncertainty, teacher stability and full data-generation/training/refresh cost. Resume tests apply at each implemented job boundary; a tiny working analyzer must not be blocked by unimplemented GPU training infrastructure.

The paper citation in the existing plan appropriately motivates a sampling experiment. The primary [Prioritized Experience Replay paper, section 3](https://arxiv.org/html/1511.05952) explicitly distinguishes replay selection from what is stored and discusses noise/diversity problems. This audit's uniform-first supervised schedule, label rules and deletion gates are project recommendations, not established Congklak findings from that paper. The [Expert Iteration paper](https://proceedings.neurips.cc/paper_files/paper/2017/hash/d8e1344e27a5b08cdfd5d027d9b8d6de-Abstract.html) was checked as the primary linked planning/learning reference; no further source summary is repeated here.
